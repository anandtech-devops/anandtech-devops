## 🚀 Featured Project

### Food Delivery Order Management System

**End-to-end DevOps implementation for deploying a containerized Spring Boot application on AWS and Kubernetes.**

<a href="https://github.com/anandtech-devops/Food-Delivery-Service">
  <img src="https://img.shields.io/badge/PROJECT-Food%20Delivery%20Service-2563EB?style=for-the-badge&logo=github&logoColor=white" alt="Food Delivery Project"/>
</a>

<br/><br/>

| Component | Technology |
|---|---|
| Application | Java, Spring Boot, MySQL |
| CI/CD | Jenkins, Maven |
| Containerization | Docker |
| Image Registry | AWS ECR |
| Infrastructure | AWS EC2, RDS |
| Orchestration | Kubernetes, Helm |
| Networking | Flannel, Ingress |
| Monitoring | Prometheus, Grafana |

### Architecture

```text
       Developer
           |
           v
      GitHub Repo
           |
           v
    Jenkins CI/CD
           |
      +----+----+
      |         |
    Maven     Docker
      |         |
      +----+----+
           |
           v
        AWS ECR
           |
           v
   Kubernetes Cluster
      (EC2 / kubeadm)
           |
       Helm Deploy
           |
      +----+-----+
      |          |
    Ingress   Application
                  |
                  v
               AWS RDS
                MySQL
```

### Key Implementation Highlights

- Built an automated CI/CD workflow using Jenkins and Maven.
- Containerized the Spring Boot application using Docker.
- Published application images to Amazon ECR.
- Deployed the application on a self-managed Kubernetes cluster using Helm.
- Integrated AWS RDS MySQL for application data persistence.
- Configured Kubernetes Services, Ingress, and Flannel networking.
- Practiced application deployment verification and monitoring using Prometheus and Grafana.
