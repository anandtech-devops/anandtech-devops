## 🚀 Featured Project

### Food Delivery Order Management System

An end-to-end DevOps project demonstrating application
containerization, CI/CD automation, cloud image
management, Kubernetes deployment, and monitoring.

**Tech Stack:** Java, Spring Boot, MySQL, Jenkins,
Docker, AWS ECR, Kubernetes, Helm, Prometheus, Grafana.

- Automated application build and container image delivery
  using Jenkins.
- Stored and managed Docker images in AWS ECR.
- Deployed the application to a self-managed Kubernetes
  cluster using Helm.
- Integrated AWS RDS MySQL for application persistence.
- Configured Kubernetes networking and application
  access through Ingress.
- Practiced application and infrastructure monitoring.

🔗 [View Project Repository](https://github.com/anandtech-devops/Food-Delivery-Service)
